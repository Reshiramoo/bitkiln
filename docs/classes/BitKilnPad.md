# BitKilnPad

**Inherits:** [BitKilnOp](BitKilnOp.md)

Adds transparent space around every frame, so outlines, shadows and glows that come after it have room and aren't cut off at the frame's edge.

## Properties

| Type | Name | Default |
|---|---|---|
| int | [bottom](#property-bottom) | `1` |
| int | [left](#property-left) | `1` |
| int | [right](#property-right) | `1` |
| int | [top](#property-top) | `1` |

## Property Descriptions

<a id="property-bottom"></a>
### int bottom = `1`

Pixels added at the bottom of every frame.

---

<a id="property-left"></a>
### int left = `1`

Pixels added on the left of every frame.

---

<a id="property-right"></a>
### int right = `1`

Pixels added on the right of every frame.

---

<a id="property-top"></a>
### int top = `1`

Pixels added at the top of every frame.
